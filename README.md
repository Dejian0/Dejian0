# Dejian Zhou

Mechanical engineering student at **ETH Zurich**, on exchange at **MIT**. I work on robot learning:
reinforcement learning, GPU-parallel simulation, and soft robots.

### Now
- **MIT CSAIL, Distributed Robotics Lab** (Prof. Daniela Rus): sensorized digital twin of a tendon-driven
  soft robot arm in a GPU-parallel Cosserat-rod simulator; RL policies for whole-arm grasping in clutter

### Previously
- **ETH Zurich, Robotic Systems Lab** (Prof. Marco Hutter): massively parallel deep RL for ANYmal-D on complex
  obstacles in Isaac Lab; distilled eight task-specific teacher policies into one depth-camera policy;
  multi-GPU training on the Euler cluster
- **PVelion**, Co-Founder: self-cleaning solar panels (Startup Campus Class Winner 2024, Innosuisse funding)

Most of my research code lives in private lab repositories.

### Tools
Python · PyTorch · TypeScript · C++ · Isaac Lab · Newton · RSL-RL · FastAPI · PostgreSQL · Docker · Slurm
